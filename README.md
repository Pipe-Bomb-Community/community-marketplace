A marketplace database of community plugins for Pipe Bomb.

## Usage

To get quick access to many community plugins, add the following URL to your Pipe Bomb server as a Marketplace:

```
https://raw.githubusercontent.com/Pipe-Bomb-Community/community-marketplace/refs/heads/master/marketplace.json
```

## Credits & Contributing

Credit goes to the maintainers of the individual plugins. If you have a plugin you'd love to add to this list, make a PR!
